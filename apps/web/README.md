# FretWays web player

Browser preview of the guitar player: microphone listening, audio-file chord chart, YouTube and Spotify playback, fretboard, and phrase composition.

This is not the Android app. Streaming links play in the page. Chord listening uses the microphone or an audio file, because the browser cannot read a streaming service audio track.

```
cd apps/web
npm ci
npm run dev
```

The dev server listens on port 8080.
